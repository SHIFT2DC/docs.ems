# Introduction

Welcome to the documentation for EMS4DC, an energy management system (EMS) for DC systems developed as part of the SHIFT2DC project. This guide will help you get started quickly and provides comprehensive reference material.

## Features

- **Modern user interface** to configure and monitor energy assets

![](/img/home-dashboard.png)

- **Historical data logging** via database integration

![](/img/charts-dashboard.png)

- **Modbus configuration** to adapt the system to assets installed in the building or microgrid

![](/img/afe-droop-modbus.png)

- **Calculated metrics and KPIs** for easier evaluation

![](/img/metrics-dashboard.png)

- **Optimization module** — provides reference setpoints for energy assets

- **Forecasting module** — predicts future energy generation and consumption
